# Image placeholders

Suggested drop-in points (each is marked with an `IMAGE PLACEHOLDER`
comment in `index.html`):

| file | used for |
|---|---|
| `logo.svg` | header logo — currently an inline ⌨ glyph |
| `avatars/<username>.png` | profile avatar — currently an initial in a gold circle |
| `bg.webp` | optional page background texture (wire into `body` background in `css/style.css`) |
